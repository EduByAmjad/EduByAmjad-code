# EduByAmjad - Code

Mathematica code, simulations and datasets for EduByAmjad videos.
Download the code, run it in Mathematica, and follow along with the video.

Playlist: https://www.youtube.com/@EduByAmjadOfficial

## Repository Structure
```edubyamjad-code/
├── 01-Microeconomics/
├── 02-Macroeconomics/
├── 03-Econometrics/
└── 04-Mathematical-Economics/```

## What Is Inside Each Folder?

### 01-Microeconomics
Code for Microeconomics videos.
**Syllabus Covered:** AP Microeconomics, IB Economics HL/SL, Cambridge A-Level Economics 9708, University Microeconomics

### 02-Macroeconomics
Code for Macroeconomics videos.
**Syllabus Covered:** AP Macroeconomics, IB Economics HL/SL, Cambridge A-Level Economics 9708, University Macroeconomics

### 03-Econometrics
Code for Econometrics videos.
**Syllabus Covered:** University Econometrics - Regression Analysis, Data Simulation, Hypothesis Testing & Optimization

### 04-Mathematical-Economics
Code for Mathematical Economics videos.
**Syllabus Covered:** University Mathematical Economics, Econometrics & Optimization

## How To Use

1. Open a folder for your course
2. Download the `.nb` file
3. Open it in Mathematica
4. Watch the matching video on EduByAmjad while you run the code
